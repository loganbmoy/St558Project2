This is an app that examines the Melbourne Housing data located here: https://www.kaggle.com/datasets/anthonypino/melbourne-housing-market/data

In this application, the user can subset the data by property sale year, property region, distance from the nearest central business district, and price.
The user can also view this subsetted dataset and download a copy of it.
With the subsetted dataset, the user can view graphs and summaries of the data with variables of their choice.

More information is in the About tab in this app.
